HOODIEGHOST GROWS — OPEN TENT VERSION

Upload the contents of this folder to the root of your GitHub Pages repository.
Replace the existing index.html and add the other files alongside it.

Included:
- index.html: responsive dashboard, current local editable readings, plant/tent tracker,
  stage target configuration, alerts, chart, journal and backup/restore.
- open-grow-tent.jpg: approved open-tent centerpiece image (also embedded in index.html).
- hoodieghost-logo.jpg and app icon PNGs: supplied HOODIEGHOST logo artwork.
- manifest.webmanifest: installable app metadata.

The tent image is a visual centerpiece with animated lighting overlays. It is not a live camera.
Readings are entered manually for now; VIVOSUN E42A integration can be added later.
The app stores data in the browser on each device; it does not sync devices yet.
